# Lunar Outpost: Mission 01

NASA Space Apps Challenge 2026 - Build a Junior Astronaut Mission Trainer.
A top-down 2D lunar outpost game (Godot 4, web build) for ages 7-12: walk around the base, manage power, life support, food, radiation shielding and delayed communications, and survive 10 days.

NASA data: DONKI (storm scenarios), OSDR (fact cards). Cached data is labelled as saved data. Game values are simplified.
See docs/ for mechanics, architecture and data sources.
